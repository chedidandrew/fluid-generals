Command & Conquer: Fluid Generals
v1.0.2 - independent community modification

Normal-speed 120 Hz simulation, independent of monitor refresh rate.
Rendering follows your display, up to 240 FPS.

FEATURES
- Fullscreen, borderless and windowed; adjustable resolution.
- Farther zoom with extended ground rendering.
- 3x faster zoom and edge scrolling; minimap left-click dragging.
- Windowed/borderless play continues when switching apps.
- Animation, camera, audio, physics, flight and combat timing fixes.
- Multiple instances; separate saves/settings; counters hidden by default.

INSTALL
1. Install/update your owned Generals; run once, then close.
2. Extract this ZIP; open FluidSetup.exe.
3. Choose your install location/game folder(s); click Install / Update.
4. Play using the new Fluid desktop shortcut(s).

Requires Windows 10/11. Microsoft runtime included. Setup files can be deleted
after installation. Keep the original games installed. Retail executables intact.

120 Hz default; 30 Hz Original; 60/144/240 Hz Experimental. Rate changes require
restart; saves/replays stay separate by rate. Display settings are in Options.
Optional troubleshooting counters: launch with -Diagnostics.

Heavy battles can still lag. Other mods/multiplayer are not certified.
Repair keeps saves/settings; Reset backs them up. Uninstall keeps them by
default. FluidUninstall.exe is also available in your install location.
Installed source/licenses: Source/ and licenses/ in your chosen location.
