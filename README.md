# Command & Conquer: Fluid Generals
## Command & Conquer: Fluid Generals Zero Hour

Rebuilt engines with normal-speed 120 Hz simulation, borderless/windowed play, farther zoom, faster camera controls, minimap dragging, and timing fixes. Rendering follows your display, up to 240 FPS.

- Fullscreen, borderless and windowed; adjustable resolution.
- Farther zoom with extended ground rendering.
- 3x faster zoom and edge scrolling; minimap left-click dragging.
- Windowed/borderless play continues when switching apps.
- Animation, camera, audio, physics, flight and combat timing fixes.
- Multiple instances; separate saves/settings; counters hidden by default.

**Install:** [Download v1.0.0](https://github.com/chedidandrew/fluid-generals/releases/tag/v1.0.0), extract, run `INSTALL.cmd`, then use the Fluid desktop shortcuts. Requires Windows 10/11 and your installed games; Microsoft runtime included. Keep the extracted folder in place.

120 Hz default; 30 Hz Original; 60/144/240 Hz Experimental. Rate changes require restart; saves/replays stay separate by rate. Heavy battles can lag; other mods/multiplayer are not certified.
